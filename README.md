# Graph state entanglement explorer

In this work, we investigate how does changing a graph affect the entanglement. We implement functions returning state vector of a quantum state, graph states, corresponding stabilizers, and conditions of checking entanglement. Through this project, we are looking for an answer for questions of "is this graph state AME(n ,q), k-uniform state, maximally entangled". In the README, we will research these concepts.
